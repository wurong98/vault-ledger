# 蓝鲸账本

程序开源、数据私有的个人账单管理工具。手机浏览器上传账单截图并补充说明，由 DeepSeek 提取为结构化记录，确认后加密保存在本机；支持借还款、多账本、自然语言查询，以及完整的加密备份下载与恢复。

数据默认只存在你自己的机器上（`~/.local/share/ledgerbox`），密码不上传任何服务器。

## 功能范围

- 手机优先的界面：截图录入、完整原图查看、流水筛选、修订与作废、借还款汇总、AI 查询。
- 数据加密落盘：scrypt 派生密钥 + AES-256-GCM，附件单独加密，密钥不进入前端包。
- 借还款结构化：借出 / 借入 / 收回 / 归还，按联系人分方向统计，允许部分还款。
- 自然语言查询：模型只输出受约束的查询意图，金额与筛选在本机完成。
- 备份与恢复：每次点击下载生成一份完整加密快照（`.ledgerbox`），可在新数据目录恢复。

第一版不做：Git 自动同步、银行抓取、多币种、逐笔核销、原生 App、离线可用。

## 环境要求

- Ubuntu 24+（开发与验收环境为 Ubuntu 26.04.1）
- Node.js ≥ 22.12（验收环境为 22.23.3）
- npm 10+

## 快速开始

```bash
npm install
npm run build          # 构建共享契约、服务端与前端
npm start              # 启动单进程服务，默认 http://127.0.0.1:8000
```

首次访问 `http://127.0.0.1:8000`：设置解锁密码（至少 6 位）→ 配置 DeepSeek API Key → 创建第一个账本。

解锁密码有冷却保护：前 3 次输错不冷却，第 4 次失败后进入 1 分钟冷却，之后逐级拉长为 1 小时 → 1 天 → 1 周 → 1 月 → 1 年；冷却期内即使密码正确也会被拒。计数只在内存中，重启服务即重置。

DeepSeek API Key 可在网页设置中配置。以下环境变量用于按需调整服务端运行参数：

| 变量 | 默认 | 说明 |
|---|---|---|
| `HOST` | `127.0.0.1` | 监听地址，默认不暴露公网 |
| `PORT` | `8000` | 端口 |
| `DATA_DIR` | `~/.local/share/ledgerbox` | 数据目录，权限 0700 |
| `APP_ORIGIN` | `http://127.0.0.1:8000` | 生产环境需显式设置为 HTTPS 源，用于同源校验 |
| `SESSION_IDLE_MINUTES` | `30` | 空闲锁定时间 |
| `DEEPSEEK_API_KEY` | 无 | 环境变量注入的 Key，优先于界面保存值，且不随备份迁移 |
| `DEEPSEEK_MODEL` | `deepseek-flash` | 模型名，需支持图文输入 |
| `MAX_IMAGE_BYTES` | `8388608` | 单图 8 MiB |
| `MAX_BACKUP_BYTES` | `536870912` | 归档/恢复上限 512 MiB |

## 手机访问

```bash
HOST=0.0.0.0 APP_ORIGIN=https://your-tailscale-host npm start
```

建议用 Tailscale Serve 或自备 HTTPS 反向代理。HTTP 仅用于可信测试环境，**不保护密码传输的机密性**。主机必须保持运行，手机才能随时录入与查询。

```bash
npm run dev            # 前端 5173（代理 /api），服务端 8000
npm run typecheck      # 契约 + 服务端 + 前端类型检查
```

## 安全边界

- 密码不上传 DeepSeek；本项目不提供密码找回，密码遗失等于数据不可读。
- 密码尝试的冷却计数只在内存里，重启服务即清零 —— 拿到进程权限的攻击者也能借此绕过，这是刻意取舍。
- 使用环境变量提供的 Key 时，界面会标注来源；界面保存的 Key 加密落盘，接口只回显掩码。
- 备份下载后需要你在手机文件管理器确认文件确实存在，网页无法证明下载结果。
- 恢复是整个数据空间的替换，不是多份文件合并；恢复前的存储代会被保留。
- 不宣称抵御已攻陷的服务器或管理员内存读取。

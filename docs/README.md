# 蓝鲸账本项目文档

本目录是蓝鲸账本的设计与实施文档。应用代码位于仓库根目录的 `apps/`、`packages/`、`tests/`。

- [技术设计](./技术设计.md)：需求基线、用户路径、数据模型、DeepSeek 接入、加密与备份恢复。
- [实施文档](./实施文档.md)：工程结构、阶段划分、接口、配置、测试矩阵与验收脚本。

第一版：手机上传完整截图与说明 → DeepSeek 提取 → 编辑确认 → 加密保存 → 查看与自然语言查询；支持借还款和账本切换。每次点击下载生成一份完整加密备份，可上传恢复。首次页面配置密码和 DeepSeek API Key。

Git 自动同步、定期云备份和银行对账不属于第一版。

## 当前实现状态

P0–P7 已实现，自动化测试 21 项全部通过（`npm test`），其中 `tests/e2e/acceptance.test.ts` 对应实施文档 §8 的 12 步验收脚本。

尚未验证：真实 DeepSeek API 调用（需真实 Key）、Android / iPhone 真机操作。这两项在实施文档 §9 中明确标记为“未验证”，不得据自动化测试宣称通过。

旧的 Python 设计不再作为本版实施依据。
